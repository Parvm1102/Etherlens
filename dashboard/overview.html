How it works

From a public dataset to a verifiable report

Raw data lands in a bronze layer that is never edited. Spark cleans it into silver, aggregates it into small gold tables, and every analysis reads from there. Times are wall-clock per cluster job.

      Diagnostic, predictive and prescriptive analytics

      When is it cheapest to send a transaction?

      Gas price is what a sender pays per unit of work, in gwei (one billionth of an ether). Busy hours bid it up.

      Big data engines

      Hadoop MapReduce and Spark on the same job

      Both engines counted transactions per sender over the same edge list stored on HDFS. MapReduce writes to disk between phases; Spark keeps intermediate data in memory.

      Graph analytics

      The most central addresses

      PageRank on Spark RDDs over the last 7 days of sender-to-receiver links, using the class formula (0.15 + 0.85 × incoming share, 10 iterations).

      Machine learning

      Unusual addresses, found without labels

      Spark MLlib KMeans groups addresses by behaviour (volume, value, nonce, gas, counterparties). An address is flagged when it is very far from its cluster's centre or sits in a tiny cluster.

      Real-time processing

      Streaming with windows and sketches

      A poller writes one file per block. Spark Structured Streaming aggregates them in 1-minute tumbling and 5-minute sliding windows, while small probabilistic sketches count senders using kilobytes instead of a full table.

      Blockchain

      Reports anyone can check

      A smart contract cannot compute analytics, so a publisher posts the results. Each day's report rows are hashed into a Merkle tree and only the 32-byte root is stored on-chain. Any single row can then be proved part of the published report, and any edit breaks the proof.

      Validation

      What was checked

      Results on synthetic data with planted anomalies were compared with known answers before trusting the real run.

        Data: Ethereum mainnet transactions, 1–31 January 2025, from the BigQuery public dataset crypto_ethereum.transactions. Processed on Google Cloud Dataproc 2.2 (Spark 3.5, Hadoop 3.3, Hive). Contract on the Sepolia test network.
