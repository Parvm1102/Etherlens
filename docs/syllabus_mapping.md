# Syllabus Mapping — where each topic lives in EtherLens

This file answers "where in your project is <topic>?" for every row of the syllabus tables in `PROJECT_SPEC.md` §2. Each row gives the code location as `file` → `function()` (line N), one sentence on how the project uses the idea, and the evidence to open.
Evidence comes from two folders: `results/` is a local run on synthetic (mock) data with planted anomalies (bots, a wash-trading ring, whales), so we know the right answers; `results_gcp/` is real Ethereum mainnet data for January 2025, processed on Google Cloud Dataproc.
Figures are in `<folder>/figures/`, cluster screenshots are in `results/screenshots/`, and `docs/PROGRESS.md` is the build log with every number and deviation. Line numbers are correct as of 2026-10-13; if code moves, search for the function name.

**Cluster used for the real data:** Dataproc 2.2, 1 master + 4 workers (HDFS, YARN, Hive on Tez, Spark 3.5, Jupyter). All paths below are relative to the project root.

## Honest gaps and caveats

- **Kafka** is not implemented (optional P2). The file-source stream plays the message-queue role.
- **`pagerank.py` has no broadcast variable or accumulator.** The spec table lists it under shared variables; in the code it shows `cache()`, `persist()` and `checkpoint()` instead. Accumulators are in `silver.py` and the broadcast join is in `daily_report.py`.
- **Streaming on the cluster used mock blocks** (mock poller, 806 blocks); the Bloom filter there held the 7,417 addresses flagged on the real data. Live mainnet mode (`poller.py` → `run_live()`) was run on the laptop for 10 real blocks (`results/stream_live_check.json`), and `bash scripts/stream_local.sh live` runs the full live stream when `ETH_RPC_URL` is set.
- **The predictive model loses to the persistence baseline on real data** (RMSE 2.64 vs 2.24). This is reported as a finding.
- **KMeans structure is weak on real data:** silhouette is 0.24–0.28 for every k from 4 to 10, so "best k = 10" is not sharp. The far-from-centroid flags are still useful as outliers.
